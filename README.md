# 💰 Profit Calculator

A simple **Profit Calculator built using Go (Golang)** that calculates EBT, profit after tax, and profit ratio based on revenue, expenses, and tax rate.

## 🚀 Features

* Calculate **EBT (Earnings Before Tax)**
* Calculate **Profit after Tax**
* Calculate **Profit Ratio**
* Simple and beginner-friendly Go program
* Uses functions and basic Go concepts

## 🛠️ Technologies Used

* **Go (Golang)**

## 📊 How It Works

The program takes three inputs:

* **Revenue** – Total income
* **Expenses** – Total business expenses
* **Tax Rate** – Tax percentage

It then calculates:

```text
EBT = Revenue - Expenses

Profit = EBT - (EBT × Tax Rate / 100)

Profit Ratio = EBT / Profit
```

## ▶️ How to Run

Make sure Go is installed on your system.

Clone the repository:

```bash
git clone https://github.com/your-username/profit-calculator.git
```

Go to the project folder:

```bash
cd profit-calculator
```

Run the program:

```bash
go run main.go
```
